# VFR FastCut v0.2.33

VFR FastCut v0.2.33 is the first packaged release of the project, focused on fast lossless cutting of VFR video and stream VODs on Windows.

## Download

For normal use, download the Windows portable archive from the Release assets:

`VFRFastCut-v0.2.33-Windows-x64.zip`

No installation is required. Extract the archive to any folder and run `VFRFastCut.exe`.

Python, FFmpeg and the required runtime components are included in the portable package.

A separate `.sha256` file is provided so the downloaded archive can be verified.

> **Windows SmartScreen:** this first release is not code-signed, so Windows may show an **Unknown publisher** / SmartScreen warning on first launch. If the archive was downloaded from this official GitHub Release, choose **More info → Run anyway**.

## What's new in 0.2.33

- English and Russian interface.
- Automatic first-run language selection based on the Windows locale.
- Persistent language selector in the main window.
- Localized built-in F1 help, dialogs, tooltips, status messages and export progress.
- Faster selected-segment export: FFprobe scans keyframes only around the requested segment instead of the entire source video.
- Cleaner export cancellation logic using a dedicated cancellation signal.
- Public-ready project documentation, changelog, issue templates, MIT license and third-party notices.

## Main features

- VFR-friendly lossless stream-copy cutting without full video re-encoding.
- Multi-range export.
- Export of only the selected segment.
- Video + audio, video-only and audio-only (`.mka`) export.
- Preservation of multiple source audio tracks.
- Timeline zoom, scrolling, cuts, segment selection and cut navigation.
- Drag & Drop.
- Undo / Redo and restore for deleted segments.
- Preview volume control and mute.

## Important limitations

Lossless video cuts are keyframe-aligned. The actual exported boundary can therefore differ slightly from the requested position. This is expected when using FFmpeg stream copy (`-c copy`) without re-encoding.

Text overlays, transitions, filters and frame-exact video editing are not part of the 0.2.x lossless branch and are planned for later development.

## Platform

- Windows 10 / 11
- x64
- Portable package, no installer
