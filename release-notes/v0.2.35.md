# VFR FastCut v0.2.35

VFR FastCut v0.2.35 is a focused preview-compatibility update.

## Fixed

- On Windows, after a successful Drag & Drop, VFR FastCut requests foreground activation so keyboard shortcuts such as Space work immediately.
- Fixed green/corrupted preview frames that could appear after playback starts on some Windows GPU/driver combinations.
- The issue was isolated to Qt Multimedia hardware texture conversion.
- VFR FastCut now disables that texture-conversion path through an early PyInstaller runtime hook, before Qt/PySide6 runtime initialization, while keeping hardware video decoding available.

## Export behavior

Lossless export is unchanged in this release:

- FFmpeg stream copy (`-c copy`) is still used.
- No re-encoding is introduced.
- Video output remains MP4, MOV or MKV.
- Audio-only output remains MKA.
- All supported input containers from v0.2.34 remain supported.

## Runtime

The Windows portable package continues to use the project-specific minimal FFmpeg 9.0.2 runtime introduced in v0.2.34.

FFmpeg source:

`https://ffmpeg.org/releases/ffmpeg-9.0.2.tar.xz`

Source SHA-256:

`8c3850283eb25fa026482078a04051e0be17347b09ef81a0849bec15a96e002e`

The exact `ffmpeg-9.0.2-source.tar.xz` used for the runtime should be published with the Release assets.

## Notes

The preview compatibility change affects Qt Multimedia rendering only. It does not change the lossless FFmpeg export pipeline.
