# VFR FastCut v0.2.34

VFR FastCut v0.2.34 is a technical and compatibility release focused on the portable FFmpeg runtime and broader container support.

## Download

For normal use, download:

`VFRFastCut-v0.2.34-Windows-x64.zip`

No installation is required. Extract the archive and run `VFRFastCut.exe`.

A `.sha256` checksum file is provided for the portable ZIP.

## What's new in 0.2.34

- Replaced the previous general-purpose Gyan FFmpeg bundle with a project-specific minimal FFmpeg 9.0.2 runtime.
- The custom runtime is built reproducibly from the official FFmpeg release source and uses shared FFmpeg DLLs.
- Added explicit output muxer selection so the minimal runtime does not depend on file-extension format autodetection.
- Expanded supported input containers:
  - MP4
  - MOV
  - M4V
  - MKV
  - WebM
  - TS / MTS / M2TS
  - AVI
  - FLV
  - MPG / MPEG
  - WMV
- Video output containers are MP4, MOV and MKV.
- Audio-only export remains MKA.
- MP4, MOV and MKV sources keep their container as the default export choice.
- Other supported source containers default to MKV.
- Updated built-in F1 help and README documentation with supported formats and stream-copy compatibility notes.

- MSYS2 UCRT64 / GCC `16.2.0`

The exact FFmpeg source archive used for the runtime is provided separately as:

`ffmpeg-9.0.2-source.tar.xz`

## Important lossless limitation

VFR FastCut uses FFmpeg stream copy (`-c copy`) for the 0.2.x lossless workflow. Video cuts remain keyframe-aligned, so the exported boundary can differ slightly from the requested position.

A supported input container does not guarantee that every possible source codec can be copied into every output container. If MP4/MOV is incompatible with a source stream, MKV is the recommended output container.
