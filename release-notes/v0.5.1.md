# VFR FastCut v0.5.1

v0.5.1 is a critical lossless-export timing hotfix.

## Fixed

Some Matroska HEVC/H.264 recordings with reordered B-frames can expose packet DTS that are missing or effectively copied from PTS. During a normal FFmpeg stream-copy remux, those non-monotonic decode timestamps may be clamped, causing several consecutive frames to receive the same presentation time. The file can still report 60 FPS while visibly playing closer to 20–30 FPS.

VFR FastCut now detects this condition before export. When needed, it preserves the source PTS exactly and reconstructs only a monotonic DTS timeline with FFmpeg's packet-level setts bitstream filter. Video remains stream-copy and is not re-encoded.

The repair is applied through single-range export, multi-range temporary parts, audio-processing paths and final concat/remux passes.

## Regression coverage

The timestamp analyzer is covered for:

- the reproduced Matroska/B-frame DTS failure;
- valid B-frame streams with monotonic DTS;
- ordinary monotonic streams;
- implausible nominal-rate fallback;
- missing DTS and frame-rate fallback.

Windows 10/11 x64 remains the tested release platform.
