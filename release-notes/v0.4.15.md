# VFR FastCut 0.4.15

VFR FastCut 0.4.15 is a major audio-workflow and interface update over the previous public 0.2.36 release.

## Highlights

### Audio timeline

Audio is now visible directly under the video timeline.

- embedded tracks from the source video;
- external audio/media clips (WAV, MP3, M4A, AAC, FLAC, OGG, Opus, MKA and supported video containers with audio);
- drag external clips to position them;
- trim external clips from either edge;
- duplicate SFX clips and move each copy independently;
- delete accidental/unneeded copies;
- reuse the 10 most recent external audio files across sessions.

### Live preview mixer

The Play flag beside each audio row now controls membership in the mix.

- the first embedded track is enabled by default;
- newly added external audio is enabled by default;
- all enabled tracks play together during preview;
- Volume and Fade can be adjusted per track;
- the same active-track selection is used for the exported Main Mix.

This makes it possible to balance original audio, voiceover and SFX before exporting.

### Main Mix by default

Normal audio export now targets a simple end-user result:

```text
Video
Audio 1 вЂ” Main Mix [default]
```

Separate stems are still available but are disabled by default.

Main Mix is AAC stereo / 48 kHz and uses a limiter. Video remains stream-copy.

### Updated interface

- less-frequent actions moved into top menus;
- essential controls remain in the main window;
- context-sensitive `Split / Remove Cut`;
- context-sensitive `Delete / Restore`;
- stable audio area with vertical scrolling instead of resizing the preview;
- right-click audio settings;
- compact export result dialog with optional technical details.

### Preview stability and performance

The Safe Preview introduced in 0.2.36 remains based on:

```text
QVideoSink в†’ QImage в†’ QWidget
```

0.4.15 removes old diagnostic preview code and the old forced software-decoder override, allowing hardware video decoding again while keeping the safe presentation path.

The live audio mixer also avoids redundant volume updates when the effective gain has not changed.

## Important fixes

- Re-enabling an audio track after seeking now resumes it from the current playhead.
- External audio moved away from project start now keeps that timing in the exported Main Mix.
- The external-audio offset fix uses real leading silence before FFmpeg `amix`, rather than relying only on input timestamps.
- Audio clip labels no longer use a misleading dark overlay.
- Export result `OK` is the default focused action.

## FFmpeg runtime

The project still ships its own FFmpeg 9.0.2 runtime.

0.4.15 expands the old stream-copy-focused build with only the audio capabilities required for:

- external audio input;
- per-track Volume;
- Fade In / Fade Out;
- Main Mix;
- AAC output;
- real external-audio delay.

GPL, nonfree and version3 features remain disabled in the project FFmpeg build.

## Known limitations

- Lossless video cuts are keyframe-aligned rather than frame-exact.
- Main Mix and tracks with Volume/Fade changes are encoded to AAC; the video itself remains stream-copy.
- Audio waveforms are not generated.
- Video overlays/transitions/effects are outside the current lossless-cut workflow.
- Windows is the tested release platform.
## Known issue

- The original instance of an external audio track currently has no delete action in its timeline context menu. Duplicate copies can still be deleted. This is planned for a follow-up release.
