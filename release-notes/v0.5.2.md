# VFR FastCut v0.5.2

## Исправления

- Открытие видео больше не блокирует интерфейс ожиданием аудиометаданных: ffprobe работает в фоне с ограничением времени. Анализ ключевых кадров запускается сразу, параллельно с открытием видео.
- Команда «Разрезать» сразу ставит границу и перемещает курсор на ближайший внутренний ключевой кадр. При равном расстоянии выбирается более ранний. Граница на таймлайне совпадает с границей, используемой экспортом видео.
- До завершения анализа ключевых кадров разрезы недоступны. Видео можно просматривать во время анализа. При ошибке анализа разрезы остаются недоступны.
- Экспорт ждёт завершения чтения аудиометаданных. Результаты от предыдущего файла игнорируются; внешние аудиодорожки, добавленные за время анализа, сохраняются.
- Обновлены русская и английская справка. Добавлены проверки отзывчивости интерфейса, фонового импорта, границ разрезов и Undo/Redo.

## Fixes

- Read embedded audio metadata in the background with a bounded timeout, keeping the interface responsive while opening video. Keyframe analysis now starts immediately alongside source loading.
- Split immediately places both the cut and playhead on the nearest interior keyframe. Equally close keyframes choose the earlier one. Visible cut boundaries match those used by video export.
- Splitting becomes available after keyframe analysis finishes; video preview remains available during analysis. If analysis fails, splitting stays unavailable.
- Export waits for audio metadata. Stale results from previous sources are ignored, and external audio added while metadata loads is preserved.
- Updated English/Russian help and added regressions for responsive loading, background metadata, split boundaries and Undo/Redo.

## Download

For Windows 10/11 x64, download **VFRFastCut-v0.5.2-Windows-x64.zip**, extract it, and run **VFRFastCut.exe**. Python and FFmpeg are included.

The `.sha256` file contains the portable ZIP checksum. The other source archives are corresponding third-party sources; they are not required to run the application.
