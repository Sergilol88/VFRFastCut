# VFR FastCut v0.2.36

VFR FastCut v0.2.36 is a focused Windows preview-stability update for VRR / Adaptive Sync / NVIDIA G-SYNC configurations.

## Fixed

- Replaced the native `QVideoWidget` presentation path with a raster preview based on `QVideoSink -> QImage -> QWidget/QPainter`.
- In testing with VRR / Adaptive Sync and G-SYNC enabled, the new preview path did not reproduce the previous black preview frames, flicker, or temporary full-monitor black screens.
- The application no longer required a per-app NVIDIA G-SYNC exclusion in the tested configuration.
- Preview state is explicitly cleared when changing/resetting media and detached safely during shutdown.

## Preview runtime

- Qt Multimedia hardware video decoding remains enabled by default.
- Qt hardware texture conversion also remains at its default behavior.
- The v0.2.35 `QT_DISABLE_HW_TEXTURES_CONVERSION=1` packaged runtime hook has been removed so the portable build matches the final tested v0.2.36 configuration.

## Export behavior

Lossless export is unchanged in this release:

- FFmpeg stream copy (`-c copy`) is still used.
- No re-encoding is introduced.
- Video output remains MP4, MOV or MKV.
- Audio-only output remains MKA.
- All supported input containers from v0.2.35 remain supported.

## Runtime

The Windows portable package continues to use the project-specific minimal FFmpeg 9.0.2 runtime introduced in v0.2.34.

FFmpeg source:

`https://ffmpeg.org/releases/ffmpeg-9.0.2.tar.xz`

Source SHA-256:

`8c3850283eb25fa026482078a04051e0be17347b09ef81a0849bec15a96e002e`

The exact `ffmpeg-9.0.2-source.tar.xz` used for the runtime should be published with the Release assets.

## Known follow-up

The raster preview currently uses more GPU 3D resources than desired on the tested system. Preview-performance optimization is intentionally deferred to a later release so v0.2.36 stays focused on display stability.
