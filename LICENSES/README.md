# Third-party license texts

This directory contains license texts used by third-party components redistributed with packaged VFR FastCut builds.

Exact third-party versions recorded for packaged releases are listed in [`../THIRD_PARTY_VERSIONS.md`](../THIRD_PARTY_VERSIONS.md).

Before publishing a binary Release:

- include the exact license texts that apply to the bundled Qt/PySide6 and FFmpeg binaries;
- record the exact shipped versions/build identifiers;
- make the corresponding source material required by the applicable licenses available through Release assets or another project-controlled location.

Official references:
- GNU GPL v3: https://www.gnu.org/licenses/gpl-3.0.txt
- GNU LGPL v3: https://www.gnu.org/licenses/lgpl-3.0.txt
- Qt for Python licensing: https://doc.qt.io/qtforpython-6/
- FFmpeg licensing: https://ffmpeg.org/doxygen/trunk/md_LICENSE.html
