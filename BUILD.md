# Building VFR FastCut on Windows

This document describes the **v0.5.0 Windows x64 release build**.

## 1. Release environment

Recorded v0.5.0 build environment:

```text
Python      3.14.5
PyInstaller 6.21.0
PySide6     6.11.2
Qt          6.11.2
FFmpeg      9.0.2 (project export runtime)
MSYS2       UCRT64
GCC         16.2.0 (Rev4, Built by MSYS2 project)
```

The exact MSYS2 runtime package owners and versions are recorded dynamically in `tools\ffmpeg-minimal\runtime\BUILD_INFO.txt` by the FFmpeg build. Do not hard-code an old GCC runtime package name here: current MSYS2 can split/rename runtime packages while the produced DLL set remains valid.

Verify the Python environment before building:

```powershell
python --version
python -m PyInstaller --version
python -c "import PySide6; from PySide6.QtCore import qVersion; print('PySide6:', PySide6.__version__); print('Qt:', qVersion())"
```

Install the pinned Python dependency:

```powershell
python -m pip install -r requirements.txt
python -m pip install pyinstaller==6.21.0
```

## 2. Build and verify the minimal FFmpeg runtime

The portable release uses the project runtime under:

```text
tools\ffmpeg-minimal\
```

Run from **MSYS2 UCRT64**:

```bash
cd /c/Users/user/VFRFastCut
./tools/ffmpeg-minimal/build-msys2-ucrt64.sh
```

The repository contains `.gitattributes` forcing `*.sh` to LF. If an older checkout still has CRLF in the build script, convert it to LF once before executing it.

The runtime is created in:

```text
tools\ffmpeg-minimal\runtime\
```

The exact FFmpeg source archive used by the build is retained as:

```text
tools\ffmpeg-minimal\ffmpeg-9.0.2-source.tar.xz
```

The v0.5.0 build intentionally keeps GPL/nonfree/version3 features disabled and enables only the demuxers, audio decoders, AAC encoder and audio filters needed by VFR FastCut.

Verify the runtime from PowerShell with a representative real VFR/Twitch file:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass `
  -File ".\tools\ffmpeg-minimal\verify.ps1" `
  -InputFile "D:\video\sample-vod.mp4"
```

Do not continue to a release build unless all capability and smoke tests pass.

## 3. Third-party licensing prerequisites

VFR FastCut itself is MIT-licensed. The portable package also redistributes third-party binaries.

Before publication:

- keep the complete `LICENSES` directory in the portable package;
- keep `THIRD_PARTY_NOTICES.md` and `THIRD_PARTY_VERSIONS.md`;
- include the Python 3.14.5 license text from the interpreter used to build the executable;
- retain the exact project FFmpeg 9.0.2 source archive generated by the project build;
- retain the FFmpeg 7.1.3 source corresponding to the Qt Multimedia FFmpeg runtime shipped by PySide6 6.11.2;
- retain corresponding source code for the LGPL Qt/PySide6 components actually shipped in the portable directory.

PyInstaller's bootloader exception allows the generated application bundle to be shipped under the application's own license, subject to dependency licenses; PyInstaller does not require its own license file to be included in the application bundle.

The v0.5.0 packaging helper prunes optional QtPdf, QML, Quick and VirtualKeyboard artifacts that generic PyInstaller hooks collect but VFR FastCut does not use. After pruning, the retained Qt/PySide6 families are covered by:

```text
qtbase-everywhere-src-6.11.2.tar.xz
qtmultimedia-everywhere-src-6.11.2.tar.xz
qtsvg-everywhere-src-6.11.2.tar.xz
pyside-setup-everywhere-src-6.11.2.tar.xz
```

The Qt Multimedia package also includes FFmpeg-family DLLs for preview/playback; retain:

```text
ffmpeg-7.1.3.tar.xz
```

Suggested location for release-only source archives:

```text
release-sources\
```

These source archives do not need to be inside the application ZIP; they can be separate GitHub Release assets, but they must remain available for the corresponding binary release.

## 4. Build the portable application

Clean previous output:

```powershell
Remove-Item .\build -Recurse -Force -ErrorAction SilentlyContinue
Remove-Item .\dist -Recurse -Force -ErrorAction SilentlyContinue
Remove-Item .\VFRFastCut.spec -Force -ErrorAction SilentlyContinue
```

Build:

```powershell
python -m PyInstaller `
  --noconfirm `
  --clean `
  --onedir `
  --windowed `
  --contents-directory "." `
  --name "VFRFastCut" `
  --icon "VFRFastCut.ico" `
  --add-data "VFRFastCut.ico;." `
  --add-data "LICENSE;." `
  --add-data "THIRD_PARTY_NOTICES.md;." `
  --add-data "THIRD_PARTY_VERSIONS.md;." `
  --add-data "README.md;." `
  --add-data "README_RU.md;." `
  --add-data "LICENSES;LICENSES" `
  vfr_fastcut.py
```

Copy the exact Python license stack used by the build:

```powershell
$PythonVersion = python -c "import platform; print(platform.python_version())"
$PythonHome = python -c "import sys; print(sys.base_prefix)"
$PythonLicense = Join-Path $PythonHome "LICENSE.txt"
if (-not (Test-Path $PythonLicense)) {
    throw "Python LICENSE.txt not found at $PythonLicense"
}
Copy-Item $PythonLicense `
  ".\dist\VFRFastCut\LICENSES\Python-$PythonVersion-LICENSE.txt" `
  -Force
```

Do **not** manually copy another FFmpeg installation from `C:\ffmpeg`.

Result before release packaging:

```text
dist\VFRFastCut\
```

## 5. Package, prune and audit

Use the release helper instead of manually assembling the portable directory/ZIP:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass `
  -File ".\tools\release\package-portable.ps1" `
  -DistDir ".\dist\VFRFastCut" `
  -RuntimeDir ".\tools\ffmpeg-minimal\runtime" `
  -OutputDir "."
```

The helper:

- copies the complete verified project FFmpeg runtime;
- removes known-unused QtPdf/QML/Quick/VirtualKeyboard artifacts collected by generic PyInstaller hooks;
- verifies required license/runtime files;
- starts the bundled project `ffmpeg.exe` and `ffprobe.exe`;
- runs `tools\release\audit-portable.ps1`;
- fails if the pruned optional Qt families reappear;
- launches `VFRFastCut.exe` briefly to catch missing DLL/plugin dependencies after pruning;
- creates the ZIP and SHA-256 file;
- re-opens the ZIP and refuses the release if required executables are missing.

Review the audit output for:

- Python DLL/runtime and OpenSSL candidates;
- remaining Qt DLLs and plugins;
- Qt Multimedia FFmpeg DLLs under `PySide6\`;
- project FFmpeg DLLs under `ffmpeg\bin`;
- exact project `BUILD_INFO.txt` package owners/versions.

Any unexpected binary dependency must be understood and covered by its redistribution terms before release.

## 6. Portable smoke test

The automated packaging helper performs a blank-app launch smoke test. Before publication, also test the extracted final ZIP with system FFmpeg unavailable so the package is proven self-contained:

```powershell
Rename-Item C:\ffmpeg C:\ffmpeg_BACKUP
```

Launch the extracted release:

```powershell
.\VFRFastCut\VFRFastCut.exe
```

Minimum release test:

1. Open a representative long VFR/Twitch video with multiple embedded audio streams.
2. Confirm the keyframe-analysis task dialog appears for a sufficiently large file, then closes cleanly.
3. Zoom the timeline until keyframe markers become visible; pan/seek/play and check for regressions or excessive UI load.
4. Create kept → deleted → kept ranges. Normal Play must skip the deleted range, while paused manual seeking can still inspect it.
5. Check deleted-head, deleted-tail and all-deleted projects.
6. Play / Pause and seek repeatedly; verify preview audio stays synchronized after Edited Preview jumps.
7. Check Safe Preview with the user's normal VRR/G-SYNC configuration.
8. Split and remove a split; Delete/Restore; Undo/Redo.
9. Multi-range stream-copy export with a middle video segment deleted.
10. Main Mix with one untouched built-in AAC track and stems off: verify the fast stream-copy path.
11. Enable a second embedded track and verify real Main Mix preview/export.
12. Change Volume and Fade on a track and verify processed AAC output. On long recordings this test is expected to take longer because audio must be decoded/processed/re-encoded; video must remain stream-copy.
13. Add external MP3; verify live preview, offset, trim and exported timing.
14. Duplicate an external clip, move the copy, then delete the copy.
15. Main Mix + separate stems.
16. Audio-only MKA export.
17. Selected-segment export.
18. Cancel export from the Task Progress Dialog, then immediately start a new export.
19. Open a second source while the first source's keyframe scan is still running; stale results must never replace the new keyframe map.
20. Reset and close the application during keyframe analysis; no hang or late UI update is allowed.
21. RU ↔ EN switching and persistence.
22. F1 help, including the audio-processing performance note.
23. Compact export-complete dialog, `Details`, `Open folder`, and default focus on `OK`.
24. Confirm the portable app still runs while `C:\ffmpeg` is unavailable.

Restore:

```powershell
Rename-Item C:\ffmpeg_BACKUP C:\ffmpeg
```

## 7. Finalize the release version

The release commit must contain:

```text
APP_VERSION = "0.5.0"
```

Run:

```powershell
python -m py_compile .\vfr_fastcut.py .\vfr_keyframes.py
python -m unittest discover -s tests -p "test_*.py"
git diff --check
```

Build the final portable package from that exact release commit.

## Notes

- `--onedir` is intentional: startup is faster, diagnosis is easier, and dynamically linked third-party libraries remain separately replaceable.
- Do not use UPX for the release unless it is explicitly tested and its effect on replaceability/licensing is understood.
- Generated `build/`, `dist/`, FFmpeg build trees/runtime, release source archives and release ZIPs should remain ignored by Git.
- Do not delete historical third-party records for older releases.
