# VFR FastCut

[English README](README.md)

**Windows 10/11 • Portable • Установка не требуется**

**VFR FastCut** — лёгкая Windows-утилита для быстрой нарезки VFR-видео с lossless stream-copy видеоряда и удобным аудиотаймлайном.

Основной сценарий: поставить разрезы, отметить ненужные фрагменты видео, при необходимости добавить и расположить звук, прослушать итоговый микс и экспортировать результат через FFmpeg. Видеоряд при возможности остаётся stream-copy; перекодируется только тот звук, которому действительно нужна обработка.

## Установка

VFR FastCut **не требует установки**.

1. Откройте раздел **Releases** репозитория.
2. Скачайте `VFRFastCut-vX.X.X-Windows-x64.zip`.
3. Распакуйте архив в любую папку.
4. Запустите `VFRFastCut.exe`.

Python, PySide6/Qt и проектный FFmpeg runtime уже входят в portable-сборку.

> **Windows SmartScreen:** неподписанная сборка при первом запуске может показать предупреждение. Если вы скачали релиз из этого репозитория и доверяете ему, выберите **Подробнее → Выполнить в любом случае**.

## Возможности

### Видео

- Быстрая нарезка без полного перекодирования видеоряда.
- Работа с VFR-записями и VOD со стримов.
- Zoom и горизонтальный скролл таймлайна, playhead, навигация по разрезам.
- Фоновый анализ keyframe с отображением маркеров keyframe на таймлайне.
- Preview смонтированного результата: обычное воспроизведение пропускает удалённые диапазоны по тем же эффективным keyframe-границам, что и экспорт, а на паузе можно вручную зайти в удалённый исходный фрагмент и посмотреть его.
- Удаление и восстановление ненужных фрагментов.
- Undo / Redo.
- Экспорт всех оставленных фрагментов или только выбранного.
- Экспорт только видео.
- Safe Preview через `QVideoSink → QImage → QWidget` без нативной video surface, которая в старых версиях могла вызывать чёрный экран и проблемы с VRR/G-SYNC.

### Аудио

- Встроенные аудиодорожки исходного видео отображаются прямо под видеотаймлайном.
- Можно добавлять внешние аудиофайлы и перемещать их по общей временной шкале.
- Внешний клип можно подрезать за левый и правый край.
- Внешний клип можно копировать для повторного использования одного SFX и удалять независимо от оригинала.
- Последние 10 добавленных внешних файлов сохраняются между запусками программы.
- Индивидуальные Volume, Fade In и Fade Out.
- Настройки любой аудиодорожки доступны по ПКМ.
- Флаги Play на таймлайне определяют, какие дорожки входят в live preview mix и экспортируемый Main Mix.
- При открытии видео в миксе по умолчанию активна только первая встроенная дорожка.
- Новое внешнее аудио по умолчанию сразу активно в миксе.
- **Main Mix включён по умолчанию.**
- Сохранение отдельных stems — дополнительная опция и по умолчанию выключено.
- Live preview одновременно проигрывает все активные дорожки, поэтому баланс можно оценить до экспорта.

### Интерфейс

- Редкие команды вынесены в верхние меню, основные команды монтажа оставлены в главном окне.
- Контекстная кнопка `Разрезать / Убрать разрез`.
- Контекстная кнопка `Удалить / Восстановить`.
- Drag & Drop.
- Русский и английский интерфейс.
- Встроенная справка (`F1`).
- Компактное окно результата экспорта с раскрываемыми техническими подробностями.
- Отдельные немодальные окна прогресса для анализа keyframe и экспорта; во время длительного анализа можно продолжать монтаж.

## Поддерживаемые форматы

### Контейнеры видео на вход

MP4, MOV, M4V, MKV, WebM, TS, MTS, M2TS, AVI, FLV, MPG/MPEG, WMV.

### Контейнеры видео на выход

MP4, MOV, MKV.

Если исходник — MP4, MOV или MKV, FastCut обычно предлагает тот же контейнер. Для остальных поддерживаемых видео по умолчанию предлагается MKV.

### Внешнее аудио / медиа

Диалог выбора принимает WAV, MP3, M4A, AAC, FLAC, OGG, Opus, MKA, MP4, MOV, MKV и WebM, если внутри есть аудиопоток. Фактическая возможность декодирования зависит от набора кодеков, включённых в комплектный минимальный FFmpeg runtime.

Экспорт только звука выполняется в MKA.

Поддержка контейнера не означает, что любая комбинация кодеков сможет быть stream-copy помещена в любой выходной контейнер. Если MP4/MOV отклоняет поток, безопаснее использовать MKV.

## Main Mix, stems и смысл Lossless Export

VFR FastCut в первую очередь является **lossless-редактором видеоряда**.

- Видео при обычном экспорте копируется без перекодирования.
- Неизменённые отдельные аудиодорожки также могут оставаться stream-copy.
- Main Mix создаётся заново и кодируется в AAC stereo / 48 kHz.
- Дорожка с изменёнными Volume или Fade обрабатывается и кодируется в AAC.
- Положение, trim и offset внешнего аудио учитываются и в Main Mix, и в stems.
- Main Mix проходит через limiter для защиты от цифрового clipping при наложении нескольких громких дорожек.

Поэтому надпись `Lossless Export` **не означает**, что любой аудиопоток всегда копируется бит-в-бит. Подробный технический отчёт доступен в окне завершения экспорта.

> **Скорость экспорта:** неизменённый звук обычно можно оставить stream-copy, поэтому даже большие записи экспортируются очень быстро. Изменение Volume/Fade или настоящий Main Mix из нескольких дорожек требуют декодирования → обработки/микширования → кодирования AAC на всей затронутой длительности, поэтому экспорт длинной записи может занять заметно больше времени. Видеоряд при этом по-прежнему остаётся stream-copy.

## Как работает lossless-нарезка видео

При обычном экспорте VFR FastCut не декодирует и не кодирует видеоряд заново. FFmpeg копирует уже закодированные видеопакеты.

Межкадровые кодеки зависят от keyframe, поэтому запрошенные границы видеомонтажа привязываются к подходящим keyframe. Фактическая граница результата может немного отличаться от выбранной позиции — это нормальное ограничение stream-copy монтажа.

Audio-only и обработанный звук используют тайминг аудиопакетов / фильтров и не зависят от видеокейфреймов таким же образом.

## Работа с аудиотаймлайном

- Нажмите `▶ / ▷` слева от аудиодорожки, чтобы включить или исключить её из preview/Main Mix.
- Перетаскивайте внешний аудиоблок для изменения его позиции в проекте.
- Тяните левый или правый край внешнего блока для trim.
- ПКМ по любой аудиодорожке открывает Volume / Fade.
- ПКМ по внешнему клипу позволяет создать копию.
- ПКМ по созданной копии позволяет удалить только эту копию.

Дорожки, снятые в списке доступных аудиодорожек, на таймлайне не отображаются.

## Запуск из исходников

Этот раздел предназначен для разработчиков. Обычным пользователям лучше использовать portable ZIP из **Releases**.

Окружение релиза v0.5.0:

- Windows 10/11 x64
- Python `3.14.5`
- PySide6 `6.11.2`
- Qt `6.11.2`
- PyInstaller `6.21.0`
- FFmpeg / FFprobe `9.0.2` — проектный минимальный runtime

Установка Python-зависимости:

```powershell
python -m pip install -r requirements.txt
```

Запуск:

```powershell
python vfr_fastcut.py
```

FFmpeg / FFprobe ищутся в следующем порядке:

1. папка приложения / упакованный `ffmpeg\bin`,
2. `tools\ffmpeg-minimal\runtime` при запуске из репозитория,
3. `C:\ffmpeg\bin`,
4. `PATH`.

## Текущие ограничения

- Lossless-видеомонтаж привязан к keyframe и не является покадрово-точным.
- Видеооверлеи, переходы, композитинг и другие видеофильтры не входят в текущий stream-copy workflow.
- Waveform не генерируется: аудио отображается в виде клипов на таймлайне.
- Live preview использует несколько Qt-аудиоплееров. В обычном миксе результат должен быть близок к экспорту, но на намеренно перегруженных пиках возможна небольшая разница, потому что экспортируемый Main Mix дополнительно проходит через FFmpeg limiter.
- Основная тестируемая платформа — Windows.
