# VFR FastCut

[English README](README.md)

**Windows 10/11 • Portable • Установка не требуется**

**VFR FastCut** — лёгкая Windows-утилита для быстрой lossless-нарезки VFR-видео, в первую очередь записей и VOD со стримов.

Основная идея: поставить разрезы, отметить ненужные фрагменты и экспортировать результат через FFmpeg **stream copy (`-c copy`)**, не перекодируя всё видео целиком.

## Установка

VFR FastCut **не требует установки**.

1. Откройте раздел **Releases** репозитория.
2. Скачайте архив последней версии `VFRFastCut-vX.X.X-Windows-x64.zip`.
3. Распакуйте архив в любую папку.
4. Запустите `VFRFastCut.exe`.

Python, FFmpeg и другие runtime-компоненты отдельно устанавливать не нужно — всё необходимое уже входит в portable-сборку.

> **Windows SmartScreen:** неподписанная сборка при первом запуске может показать предупреждение. Если вы скачали релиз из этого репозитория и доверяете ему, выберите **Подробнее → Выполнить в любом случае**.

### Обновление

Скачайте более новую версию из **Releases** и распакуйте её в новую папку либо замените предыдущую portable-папку. Настройки приложения, например выбранный язык интерфейса, хранятся отдельно и не должны сбрасываться при замене файлов программы.

## Возможности

- Lossless-нарезка видео без полного перекодирования.
- Работа с VFR-записями.
- Таймлайн с zoom, горизонтальным скроллом, разрезами, выбором сегментов и навигацией по playhead.
- Экспорт всех оставленных сегментов или только текущего выбранного фрагмента.
- Экспорт видео + звук, только видео или только звук.
- Audio-only экспорт в `.mka` с сохранением исходного аудиокодека и параметров потоков.
- При включённом звуке сохраняются все аудиодорожки.
- Drag & Drop.
- Undo / Redo и восстановление удалённого фрагмента.
- Регулятор громкости и Mute для preview.
- Русский и английский интерфейс с автоматическим выбором языка при первом запуске и сохранением ручного выбора.
- Встроенная справка (`F1`) с описанием функций, хоткеев и ограничений lossless-режима.
- Не нужны аккаунт, облако или API-токены.

## Как работает lossless-нарезка

При обычном экспорте VFR FastCut не декодирует и не кодирует видеоряд заново. FFmpeg копирует уже готовые закодированные пакеты в новый файл.

Из-за устройства межкадровых видеокодеков границы видео приходится привязывать к подходящим keyframe. Поэтому фактическая точка разреза может немного отличаться от выбранной позиции. Для stream-copy монтажа без перекодирования это нормальное ограничение.

При экспорте только звука видеокейфреймы не нужны — границы идут по аудиопакетам.

## Язык интерфейса

При первом запуске VFR FastCut выбирает русский язык, если Windows использует русскую локаль. Для остальных локалей по умолчанию используется английский. Язык можно в любой момент переключить селектором в правой верхней части окна; выбор сохраняется между запусками.

## Запуск из исходников

Этот раздел предназначен для разработчиков и участников проекта. Обычным пользователям лучше использовать готовый portable ZIP из **Releases**.

- Основная целевая платформа — Windows 10/11.
- Python 3.10+
- PySide6 6.11.2 для воспроизводимых релизных сборок
- FFmpeg и FFprobe

Установка Python-зависимости:

```powershell
python -m pip install -r requirements.txt
```

Запуск:

```powershell
python vfr_fastcut.py
```

FFmpeg/FFprobe ищутся в следующем порядке:

1. `ffmpeg\bin\` рядом с программой,
2. `C:\ffmpeg\bin\`,
3. `PATH`.

## Текущие ограничения

- В lossless-режиме границы видео привязаны к keyframe.
- Текст, переходы, фильтры и покадрово-точные изменения видеоряда потребуют перекодирования и намеренно отложены до ветки 0.3.x.
- Preview работает через Qt Multimedia / `QVideoWidget`; на некоторых конфигурациях VRR/G-SYNC возможно мерцание. Для затронутых систем помогает Fixed Refresh для `VFRFastCut.exe` в профиле NVIDIA.
- Релизно тестируется Windows. Другие ОС пока не проверяются как целевые.
